== Quick Start ==

  1. Create an API key in any namespace:

     kubectl create namespace team-alpha
     kubectl apply -n team-alpha -f - <<EOF
     apiVersion: kaito.sh/v1alpha1
     kind: APIKey
     metadata:
       name: default
     spec:
       prefix: "sk-"
       expiresIn: "720h"
     EOF

  2. Retrieve the generated key:

     kubectl get secret llm-api-key -n team-alpha -o jsonpath='{.data.apiKey}' | base64 -d

  3. Verify with kubectl:

     kubectl get apikey -n team-alpha
